# PYEODA 판매·결제·로그인 운영정책 v1.0

작성일: 2026-10-02
수익 구조 개정: 2026-10-07 — 펴다뮤직과 공통 모델. 아래 배분율은 운영 확정 전 검토 예시입니다.

## 1. 기본 원칙

PYEODA는 독자가 로그인 없이 작품을 탐색하고 무료 회차를 읽을 수 있도록 한다.

로그인은 결제가 필요한 순간에만 요구한다.

- 무료 작품 탐색: 로그인 불필요
- 무료 회차 읽기: 로그인 불필요
- 유료 회차 구매: 로그인 필요
- 완결작 전체 소장 구매: 로그인 필요
- 포인트 충전 및 구매내역 복원: 로그인 필요
- 작가 스튜디오 및 작품 관리: 작가 로그인 필요

## 2. 작품 판매 방식

작가는 작품별로 판매 방식을 선택할 수 있다.

### A. 전체 무료

- 모든 회차를 무료로 공개한다.
- 독자는 로그인 없이 끝까지 읽을 수 있다.
- 무료 작품에는 플랫폼 판매 수수료가 발생하지 않는다.

### B. 부분 유료 연재

기본 정책:

- 1화~5화: 무료
- 6화부터: 유료
- 유료 회차 가격: 작가가 직접 설정
- 필요 시 특정 회차를 개별 무료로 변경할 수 있도록 확장 가능

작가 설정 화면 예시:

- 판매 방식: 부분 유료 연재
- 무료 회차: 기본 5화
- 회차 가격: 작가 직접 입력
- 이후 등록되는 회차에는 기본 회차 가격을 자동 적용

### C. 완결 후 전체 소장

- 작품 완결 후 작가가 전체 소장 가격을 직접 설정한다.
- 부분 유료 연재 작품도 완결 후 전체 소장 판매를 함께 운영할 수 있다.
- 전체 소장 구매자는 해당 작품의 모든 회차를 열람할 수 있다.

## 3. 결제 수단

회차마다 카드 결제를 반복하지 않는다.

PYEODA 내부의 **충전금/포인트 방식**을 사용한다.

기본 흐름:

1. 독자가 PYEODA 포인트를 충전한다.
2. 유료 회차를 선택한다.
3. 해당 회차 가격만큼 포인트가 차감된다.
4. 구매한 회차는 다시 결제하지 않고 계속 열람할 수 있다.
5. 웹에서 구매한 회차는 같은 계정으로 로그인한 모바일에서도 열람할 수 있다.

완결작 전체 소장 역시 충전한 포인트로 결제한다.

## 4. 펴다뮤직과 공통 수익 구조

- 독자 월 이용권은 운영하지 않는다. 무료 작품·무료 회차는 로그인 없이 읽는다.
- 작가 요금제는 선택형 창작 도구 구독이다. Free 0원, Creator 월 4,900원, Pro 월 9,900원, Studio 월 19,900원은 가격 초안이며 아직 청구하거나 기능을 제한하지 않는다.
- 소장 판매: 작가 85% / 플랫폼 15% **예시**.
- 팬 후원: 작가 90% / 플랫폼 10% **예시**. 후원 결제는 준비 중이다.
- 유료 회차 및 소장 판매가는 작가가 설정한다. 뮤직의 소장 1,500원 예시는 북스 작품 가격에 일괄 적용하지 않는다.
- 배분 예시는 결제 수수료·환불·세금 공제 후 순매출 기준이다. 공제 항목과 최종 정산률은 운영 전 별도 확정한다.
- 작가 구독료는 창작 도구 이용 매출이며 작품 판매·후원 정산 재원에 섞지 않는다.
- 외부 유통은 향후 확장 항목이다. 현재 자동 정산이나 배분율 확정을 의미하지 않는다.

소장 순매출 4,900원인 경우의 검토 예시: 플랫폼 735원 / 작가 4,165원.
후원 순매출 10,000원인 경우의 검토 예시: 플랫폼 1,000원 / 작가 9,000원.

이 예시로 기존 거래를 재계산하지 않는다. 기존 거래의 저장된 정산 금액과 과거 정책은 보존한다. 실매출·지급액 집계에는 거래 당시 확정된 금액을 사용한다.

## 5. 독자 로그인 정책

PYEODA 전체를 회원 전용으로 만들지 않는다.

독자는 작품을 구경하고 무료 회차를 읽는 동안 로그인할 필요가 없다.

다음 동작을 처음 시도할 때 간편 로그인을 요청한다.

- 포인트 충전
- 유료 회차 구매
- 전체 소장 구매
- 구매내역/내 서재 복원

로그인 성공 후 사용자는 원래 진행하던 결제 화면으로 자동 복귀한다.

## 6. 간편 로그인

우선 적용 대상:

- 카카오
- Google
- 네이버

구글과 카카오는 Supabase Auth의 소셜 로그인과 연동한다.

네이버는 Supabase 기본 소셜 공급자가 아니므로 별도 OAuth 연동이 필요하다.  
네이버 개발자 애플리케이션의 Client ID / Client Secret 및 콜백 URL 구성이 완료된 뒤 서버 측 연동을 진행한다.

## 7. 구매 권한 저장 원칙

브라우저 LocalStorage만으로 구매 권한을 관리하지 않는다.

구매 권한은 서버 DB에 저장한다.

향후 필요한 주요 데이터:

### 작품

- 판매 방식
- 무료 회차 수
- 기본 회차 가격
- 전체 소장 가격
- 플랫폼 수수료율

### 회차

- 무료 여부
- 회차 가격
- 공개 여부

### 독자 지갑

- 현재 포인트 잔액
- 충전 내역
- 사용 내역

### 회차 구매

- 사용자
- 작품
- 회차
- 결제 포인트
- 구매 시각

### 전체 소장 구매

- 사용자
- 작품
- 구매 금액
- 구매 시각

## 8. 독자 화면 동작

### 무료 회차

`다음 화 →`

로그인 없이 바로 읽는다.

### 첫 유료 회차

예:

`200P로 6화 보기`

로그인하지 않은 경우:

`간편 로그인 → 포인트 확인 → 구매 → 회차 열기`

이미 로그인한 경우:

`포인트 확인 → 구매 → 회차 열기`

### 이미 구매한 회차

`구매 완료 · 바로 읽기`

추가 차감 없이 읽는다.

### 전체 소장

예:

`4,900P로 전체 소장`

구매 완료 후 모든 회차를 바로 열 수 있으며 내 서재에 저장한다.

## 9. 확정된 PYEODA 기준

- 독자는 로그인 없이 작품 탐색 가능
- 무료 작품은 끝까지 무료 공개 가능
- 부분 유료 연재 기본 무료 구간은 첫 5화
- 6화부터 회차 가격은 작가 직접 설정
- 완결 후 전체 소장 가격은 작가 직접 설정
- 유료 회차 및 전체 소장 결제는 PYEODA 포인트 사용
- 독자 월 이용권 없음 · 선택형 작가 도구 구독
- 소장 작가 85% / 후원 작가 90%는 검토 예시이며 최종 정산률은 운영 전 확정
- 결제가 필요한 순간에만 독자 로그인
- 구매 권한은 서버에 저장하여 웹·모바일에서 공유
