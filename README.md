# 오늘의 온기 v6 — 매일 바뀌는 대형 콘텐츠 라이브러리

## 화면 및 기능
이전 v5 모바일 원스크린 레이아웃을 유지합니다. 오늘의 기분(5가지) → 오늘의 위로/문장 → 작은 실천 → 한 줄 기록 → 최근 기록 → 아래 미션/이야기/내 기록 버튼으로 구성합니다. 기록 데이터 저장 키는 v4/v5와 동일해 **같은 주소의 동일한 브라우저에서는 기존 기록이 유지됩니다.**

## 콘텐츠 수량
- **오늘의 문장 400개**: 하루에 한 개씩, 날짜별로 변경; 400일 후 순환. 19개 주제별로 고르게 교차 배치.
- **매일의 짧은 이야기 186편**: v5 기존 6편 + 새 오리지널 초단편 180편. 하루 한 편씩, 186일 후 순환. 지난 7일, 전체 목록 제공.
- **자기계발 미션 240개**: 독서, 공부·일, 생활습관 각각 80개. 각 분야에서 하루 3개 제안이 날짜마다 달라지며, 같은 날 같은 미션 중복 없음. 조합은 장기간 다양하게 순환하며 개별 미션은 다시 등장할 수 있습니다.
- **감정별 위로 75개(감정당 15개)**, **작은 실천 50개(감정당 10개)**: 날짜별 자동 선택. 작은 실천은 사용자가 교체 가능.

## 출처와 저작권
저자에게 실제로 귀속시키는 가짜 인용문은 넣지 않았습니다. 칼 융의 자기 이해, 조셉 머피의 자기대화, 《시크릿》의 감사 실천, 김승호의 돈 관리, 나폴레온 힐의 목표 설정, 밥 프록터의 비전 설정 등 **일반적인 주제에서 영감을 받아 새로 쓴 창작 문장/이야기**입니다. 검증된 직접 인용문이나 원저작물의 긴 구절을 복제하지 않았습니다. 앱에서는 각 문장에 '영감을 받은 주제'를 명시합니다. 어떤 사상도 의학적 효능, 투자 수익 또는 목표 달성을 보장하지 않습니다.

## 배포
`index.html`, `app.js`, `content-v6.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icons/` 전체를 같은 폴더 구조로 정적 HTTPS 호스팅에 올리세요. GitHub Pages와 호환되는 정적 PWA입니다. `oneul_ongi_daily_demo.html`은 PC/휴대전화에서 열어보는 파일 한 장 체험본이며 PWA 설치용은 아닙니다. 새 버전에서 PWA가 이전 콘텐츠를 보여주는 경우 인터넷 연결 상태에서 새로고침하고 브라우저 캐시를 갱신하세요.

개인정보: 감정·일기·성장 기록은 브라우저 내 localStorage에만 저장되며 서버 전송·기기 간 동기화가 없습니다. 브라우저 데이터를 지우면 사라지므로 백업 기능을 이용하세요. 전문 상담/위기 대응을 대신하지 않습니다.
