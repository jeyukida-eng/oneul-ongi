# 오늘의 온기 v7 — 오늘도 잘했어요

모바일 한 화면의 기존 v6 기능을 그대로 유지하고 성취감과 자발적인 SNS 공유를 추가했습니다.

## 새 기능
- 작은 실천 완료 시 '오늘도 잘했어요!' 축하 화면 자동 표시
- 홈의 오늘 모은 온기 N개 표시와 '성취 카드 보기'
- 미션 화면에서 성취 카드 바로 열기
- 오늘/누적 온기 수, 함께한 날, 최근 7일과 6가지 성취 배지
- 인스타 스토리(1080×1920)와 피드(1080×1350) PNG 이미지 생성
- 문구 세 가지 중 선택, 완료한 실천·미션 포함 여부 선택
- 이미지 다운로드 및 모바일 공유 메뉴 지원

일기 본문과 감정 이름은 공유 이미지에 자동으로 들어가지 않습니다. 인스타그램에 자동 게시하지 않으며 사용자가 직접 업로드합니다.

기존 저장 키 oneul-ongi-mvp-v1을 유지하므로 동일 브라우저의 기록과 미션 데이터를 이어서 사용합니다. 기록은 기기 내에만 저장되므로 기기 교체 전에 백업하세요.
