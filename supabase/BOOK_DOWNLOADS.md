# 소장 PDF 자동 생성

작가가 판매용 PDF를 따로 만들거나 등록할 필요가 없다. 완결·공개된 작품의 books.price를 설정하면 독자가 소장하기에서 언어를 고르고 테스트 결제로 이동한다. 같은 책의 한국어·영어·일본어·중국어 PDF는 모두 한 가격이며, 전체 책 소장 후 다른 언어를 선택해도 추가 결제가 없다. 가격 미설정 또는 공개 원고가 없는 책은 결제를 시작하지 않는다.

승인된 전체 책 주문을 서버에서 확인한 뒤 공개 원고와 그림만 읽는다. 비공개 초안은 포함하지 않는다. 한국어는 바로 조판하며, 다른 언어는 OpenAI API로 원문을 번역한다. 모델은 gpt-4.1-mini-2025-04-14로 고정하고 store:false 및 JSON schema를 사용한다. OPENAI_API_KEY가 없거나 번역이 실패하면 외국어 PDF를 제공하지 않고 상태를 안내한다. 한국어를 번역 결과로 대체하지 않는다. 각 번역 ID의 누락·중복·빈 내용을 거절한다.

번역은 최대 3,000자/30항목의 묶음으로 처리한다. purchase_translation_chunks는 책·원고 해시·언어·묶음 번호를 복합 기본키로 캐시한다. 원고 해시는 서버가 계산하며 변경되면 새 번역을 사용한다. 90초 임대와 조건부 업데이트로 동시 중복 호출을 제한한다. 실패 시 임대를 풀고, 각 묶음은 최대 8회 시도한다. 브라우저에서 중단하거나 페이지를 다시 열어도 완료된 번역은 재사용한다. 테이블은 RLS와 anon/authenticated 접근 차단으로 서버만 읽고 쓴다.

브라우저가 기존 PDF 조판·그림 변환 기능으로 페이지를 만들고, 서버가 승인된 구매번호(payment_orders.id)를 각 페이지 중앙과 하단에 넣은 PDF만 다운로드 응답으로 전달한다. 이름·이메일은 포함하지 않는다. 작가 확인용은 AUTHOR PREVIEW 표시를 쓴다. 20MB·600페이지 범위를 지원한다. 그림은 기존 manuscript-assets 접근 검증을 거쳐 포함하며, 그림 로딩 실패 시 완성본 다운로드를 중단한다. 암호화 DRM이 아니며 일반 PDF 뷰어에서 읽을 수 있다. 브라우저가 구매한 원고를 받아 조판하므로 워터마크 제거 방지나 원문 복사를 막는 방식은 아니다.

현재 결제는 기존 토스 테스트 결제만 사용한다. 실제 청구·매출·라이브 권한은 생성하지 않는다. 실결제 전환 시 결제와 다운로드 권한의 환경 및 취소·환불 처리를 함께 연결해야 한다. 구매자가 내려받는 PDF는 모두 PDF 형식이며 EPUB 선택은 제공하지 않는다. 기존 비공개 R2 판매 파일과 소유자용 업로드 API는 호환성을 위해 보존하지만 자동 생성 흐름의 선행 조건은 아니다. 작가의 기존 EPUB 내보내기 기능도 유지한다.
