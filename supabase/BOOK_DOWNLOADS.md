# 소장 파일과 결제 연결

출판 센터 → 소장 파일 등록에서 현재 작품의 완성본을 등록한다. 한국어·영어·일본어·중국어·다국어 통합 PDF/EPUB을 지원하며 파일당 50MB 이하이다. 같은 언어와 형식으로 재등록하면 현재 판매 파일을 교체한다. 기존 객체는 보존한다.

작품을 완결·공개하고 책 정보에서 소장 가격을 설정한다. 가격은 books.price 한 값이며, 언어와 형식으로 가격을 나누지 않는다. 파일이나 가격이 준비되지 않은 작품은 소장 화면에서 결제를 시작할 수 없다.

독자는 소장하기에서 파일을 고르고 로그인 후 테스트 결제로 이동한다. 승인된 전체 책 주문만 서버가 확인하여 모든 등록 언어·형식의 다운로드를 허용한다. 결제 완료 화면과 테스트 주문내역의 소장 파일 다운로드에서 다시 받을 수 있다. 회차 구매는 책 파일 다운로드 권한을 주지 않는다.

현재 기존 토스 **테스트 결제**에만 연결되어 있다. 실제 청구·매출·라이브 구매 권한을 생성하지 않는다. 운영 결제 전환 시 checkout과 entitlement의 환경을 함께 변경하고 환불/취소에 따른 권한 회수도 연결해야 한다.

book_download_files는 RLS를 켜고 anon/authenticated의 직접 접근을 차단한다. 소장 파일은 기존 비공개 R2 버킷에 저장하며 book-downloads 함수가 로그인, 작품, 주문, 성인인증을 검사한 뒤 바이트를 전달한다. 공개 객체 URL과 공유 서명 URL은 반환하지 않는다.

검증: 새 권한·파일 형식·저장소 실패 검사 12개와 전체 기존 검사 포함 57개 통과. 실제 서버에서 빈 판매 파일 목록 응답과 미로그인 다운로드 401을 확인했다. 실제 결제→파일 전송은 작가의 파일·가격 등록과 로그인 상태에서 확인해야 한다.
