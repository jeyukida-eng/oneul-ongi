# 펴다 19+관

## 현재 구성
- 일반관: 전체·15세 작품. 19+ 작품은 일반 목록·발견·랭킹에서 제외.
- 19+관: 계정 로그인 및 서버에서 확인한 유효한 성인인증 기록이 필요. 장르별 인기·신작·완결 목록.
- 공통: 작가 계정, books/episodes, 기존 결제 주문과 정산 구조.
- 작가: 작품 이용등급 선택, 19+ 등록기준 동의. 심사 대기·승인·반려·노출 중지 상태.
- 관리자: 서버에서 부여한 app_metadata.pyeoda_admin=true인 계정만 19+ 작품 관리 가능. 본문 검토, 심사 사유, 신고 처리, 심사·제재 이력.
- 본문·작품 정보 변경은 재심사. 19+에서 일반관으로 직접 등급 변경 불가.

## 등록기준 초안 (2026-10-v1)
성인 간 로맨스 및 성인 주제 작품은 심사 후 등록한다. 미성년자의 성적 묘사, 성착취, 불법 촬영물, 실존 인물의 동의 없는 성적 콘텐츠는 금지한다. 19+ 등급은 금지 콘텐츠를 허용하는 표시가 아니다. 심사 사유와 제재 이력을 보관하고 신고를 별도 처리한다. 최종 공개 운영정책은 인증업체·결제사와의 계약 조건 및 법률 검토를 반영해 확정한다.

## 개통 전 남은 연결
1. 성인 본인인증 업체 계약 및 서버 콜백 연결. 업체 서명 검증, 거래 재사용 방지, 계정 연결과 성인 여부 검증을 통과한 경우에만 service_role 서버가 adult_verifications를 저장한다. 주민번호 등 원본 신원정보는 이 테이블에 저장하지 않는다.
2. 서버 관리자가 실제 운영 관리자 계정에 app_metadata.pyeoda_admin=true를 부여한다. 작가 가입 정보 및 user_metadata로 권한을 부여하지 않는다.
3. 성인 표지의 비공개 저장·인증된 서명 URL 연결. 준비 전 19+ 표지는 공개 book-covers에 업로드하지 않으며 서버 cover_url은 빈 값으로 제한한다. 기기 내 표지 편집은 유지한다.

로그인이나 동의 체크는 성인인증이 아니다. 현재 실인증 콜백은 미연결이고 19+관 입장은 잠겨 있다. 관리자 계정을 임의로 지정하지 않았다.

## 보안 및 검증
- adult_verifications는 본인 조회만 허용, 브라우저 쓰기 금지. 만료·철회 여부 검사.
- books/episodes는 RLS로 성인 미인증 접근 제한. 소유 작가·관리자는 작업/검토용 접근을 허용한다.
- public-episodes 및 테스트 결제 생성·승인에는 서비스 권한 우회 경로에도 별도 성인인증·심사 검사를 적용.
- public-library는 일반관만 반환. 19+관은 로그인한 클라이언트가 RLS 보호 조회.
- 심사·제재 이력은 클라이언트 수정 불가. 내부 트리거 함수는 private 스키마, search_path 고정, PUBLIC 실행권한 제거.
- PWA에서 다른 출처의 API 응답은 캐시하지 않는다.
- DB 롤백 테스트: 비로그인·미인증·심사대기·인증철회는 0행, 유효 인증+심사승인은 1행. 테스트 작품·인증 기록은 롤백으로 제거.
