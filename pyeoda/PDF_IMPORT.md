# PDF 원고 불러오기

집필 도구의 **PDF 불러오기** 또는 본문으로 PDF 끌어놓기를 사용합니다. 웹 스튜디오 왼쪽 메뉴에도 같은 버튼이 있습니다.

- 로컬 파일을 PDF.js 5.6.205로 읽고 미리보기와 페이지 범위를 표시합니다. 원본 PDF를 서버에 올리지 않습니다.
- 텍스트 모드는 추출된 본문을 새 비공개 회차 하나로 만듭니다. 다단·표·장식은 원본 배치를 재현하지 않으므로 작가가 확인해야 합니다.
- 페이지 이미지 모드는 선택한 페이지를 순서대로 JPEG로 변환하고 페이지마다 새 비공개 회차를 만듭니다. 기존 이미지 저장·R2 반영 경로를 사용합니다. OCR은 지원하지 않습니다.
- 현재 원고를 먼저 저장하고 새 회차를 추가합니다. 저장 공간 부족 시 추가 회차를 되돌리고 기존 원고를 보존합니다. 서버 반영은 각 회차의 기존 저장 버튼으로 합니다.
- 입력 20MB / 200쪽, 텍스트 50만 글자, 이미지 한 번에 20쪽 및 총 data URL 300만 글자로 제한합니다. 큰 파일은 페이지 범위를 나누어 가져옵니다.
- PDF JavaScript, 링크, 첨부파일, XFA를 가져오거나 실행하지 않습니다. `isEvalSupported:false`, 읽기 오류 시 중단, 이미지 디코딩 크기 제한을 적용합니다. CSP의 `wasm-unsafe-eval`은 함께 배포한 이미지 디코더에만 필요한 WebAssembly 실행을 허용하며 JavaScript eval은 허용하지 않습니다.
- 라이브러리·워커·CMap·표준 글꼴·이미지 디코더 및 라이선스를 같은 사이트에서 제공합니다. 확인용 HTML에도 포함되어 외부 PDF 도구에 파일을 보내지 않습니다.

검증: `node --test tests/*.test.mjs` — PDF 원고 검사 6개 포함. 실제 두 페이지 PDF의 텍스트 추출·JPEG 렌더링, 한글 줄 간격 처리, 취소, 책 변경, 저장 공간 부족 시 복구, 손상 파일 거부를 검사합니다. 테스트 실행 환경에서 설치 가능한 브라우저가 없어 실제 작성 화면의 파일 선택 UI 검증은 수행하지 못했습니다.
